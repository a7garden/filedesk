# 릴리즈 전 사람이 볼 것

`smoke.mjs` 는 WebView2 안만 조작한다. 셸 메뉴 · 앱 밖 끌기 · 설치는 Windows 가 그리는 것이라 자동 시험이 닿지 않는다.
새 판(`v<판>` 태그)을 밀기 전에 설치본으로 한 번씩 본다. 깨졌던 적이 있는 것은 README 「함정」의 증상 이름을 괄호에 적었다.

## 색인 · 빠른 색인 서비스 (2026.11.12)

- [ ] 설정 › 색인 › 「빠른 색인 서비스 설치」 — UAC 창이 뜨고, 「예」 뒤 몇 초 안에 드라이브 표가 「MFT · USN」으로 바뀐다
- [ ] UAC 에서 「아니요」 — 「관리자 권한 묻기를 취소했다」가 뜨고 앱 색인(훑기 · 감시)은 그대로 돈다
- [ ] 보안 프로그램(백신 · EDR)이 서비스나 볼륨 읽기를 막지 않는다 — 막히면 `%ProgramData%\filedesk\service.log` 를 본다
- [ ] 다른 Windows 계정으로 로그인해 `fd index status` — 파이프를 열지 못해 「색인 서비스가 없다」가 나온다 (그 계정 몫이 아니다)
- [ ] `%ProgramFiles%\filedesk\fd-indexd.exe` · `%ProgramData%\filedesk\` 를 일반 사용자 권한으로 바꿀 수 없다
- [ ] 앱을 끈 채로 파일을 만들고 지운 뒤 다시 켜면 「모든 드라이브」 찾기에 바로 반영된다 (USN)
- [ ] 실제 C: · D: 에서 `fd query "확장자:pdf" --limit 100000` 의 수가 `--live` 와 거의 같다 (MFT 풀이 대조)
- [ ] 앱 업데이트 뒤 서비스 판이 다르면 설정 › 색인에 「서비스 업데이트」가 보인다
- [ ] 앱을 지울 때 「빠른 색인 서비스도 지울까요?」가 뜨고, 「예」면 서비스 · Program Files 의 exe · ProgramData 가 사라진다
- [ ] 본문 색인이 도는 동안 노트북 팬 · 디스크가 화면을 굼뜨게 하지 않는다 · 「잠시 멈춤」이 듣는다

## 셸

- [ ] 오른쪽 메뉴 「더 보기」(또는 Shift+오른쪽 단추)로 셸 메뉴가 누른 자리에 뜬다 — 「보내기」 · 「연결 프로그램」 아래 항목이 차 있다 (「보내기」 · 「연결 프로그램」이 비어 열림)
- [ ] 오른쪽 메뉴 · 끌기가 바로 닫히지 않는다 (메뉴 · 끌기가 바로 닫힘)
- [ ] 빈 자리 오른쪽 메뉴 「더 보기」의 「새로 만들기」로 문서가 생긴다
- [ ] Alt+Enter 로 속성 창이 뜬다

## 끌기

- [ ] 앱 → 탐색기 · 바탕화면으로 끌면 복사 · 이동된다
- [ ] 탐색기 → 앱으로 끌면 같은 드라이브는 이동 · 다른 드라이브는 복사 · Ctrl 복사 · Shift 이동
- [ ] 앱 → 메일 · 메신저 창에 끌어 첨부된다

## 아이콘

- [ ] pptx · txt · dll · log · 바로가기 아이콘이 다 보인다 (아이콘이 가끔 404 · dll · log 아이콘만 실패)

## 설치 · 갱신

- [ ] 앞 판이 깔린 PC 에서 제목 줄에 「새 판」이 뜨고, 눌러 깐 뒤 다시 켜진다
- [ ] 설치 폴더에 `fd.exe` 가 있고 `fd.exe --help` 가 돈다 (설치 파일에 넣은 fd.exe 가 깨짐)
- [ ] 스킬을 깔아 둔 PC 에서 새 판을 켜면 `~/.claude/skills/filedesk/SKILL.md` 머리의 판이 새 판으로 바뀐다
