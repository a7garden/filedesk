# 릴리즈 전 사람이 볼 것

`smoke.mjs` 는 WebView2 안만 조작한다. 셸 메뉴 · 앱 밖 끌기 · 설치는 Windows 가 그리는 것이라 자동 시험이 닿지 않는다.
새 판(`v<판>` 태그)을 밀기 전에 설치본으로 한 번씩 본다. 깨졌던 적이 있는 것은 README 「함정」의 증상 이름을 괄호에 적었다.

## 셸

- [ ] 파일 오른쪽 메뉴에 「보내기」 · 「연결 프로그램」 아래 항목이 차 있다 (「보내기」 · 「연결 프로그램」이 비어 열림)
- [ ] 오른쪽 메뉴 · 끌기가 바로 닫히지 않는다 (메뉴 · 끌기가 바로 닫힘)
- [ ] 빈 자리 오른쪽 메뉴의 「새로 만들기」로 문서가 생긴다
- [ ] Alt+Enter 로 속성 창이 뜬다

## 끌기

- [ ] 앱 → 탐색기 · 바탕화면으로 끌면 복사 · 이동된다
- [ ] 탐색기 → 앱으로 끌면 같은 드라이브는 이동 · 다른 드라이브는 복사 · Ctrl 복사 · Shift 이동
- [ ] 앱 → 메일 · 메신저 창에 끌어 첨부된다

## 아이콘

- [ ] pptx · txt · dll · log · 바로가기 아이콘이 다 보인다 (아이콘이 가끔 404 · dll · log 아이콘만 실패)

## 설치 · 갱신

- [ ] 앞 판이 깔린 PC 에서 제목 줄에 「새 판」이 뜨고, 눌러 깐 뒤 다시 켜진다
- [ ] 설치 폴더에 `fd.exe` 가 있고 `fd.exe --help` 가 돈다 (설치 파일에 넣은 fd.exe 가 깨짐)
- [ ] 스킬을 깔아 둔 PC 에서 새 판을 켜면 `~/.claude/skills/filedesk/SKILL.md` 머리의 판이 새 판으로 바뀐다
